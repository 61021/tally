# Tally

Fun, brain-nourishing browser games in one place: Sudoku, and Atlas, where you pin countries on a blank map. Lives at [tally.vitex.dev](https://tally.vitex.dev).

Nuxt 4, Nuxt UI v4 and Tailwind v4 on a Cloudflare Worker.

```bash
pnpm install
vpr dev
```

Atlas's maps come from Natural Earth; `vpr atlas` downloads it and rewrites `public/atlas`.
